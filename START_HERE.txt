S GARAGE - EURO TRUCK SIMULATOR 2

1. Extract the entire ZIP first. Do not run the app inside the ZIP.
2. Double-click S Garage.exe.
3. Keep the small launcher window open while editing in your browser.
4. Choose a profile, save, and truck.
5. Close ETS2 before clicking Save changes in the garage.
6. Save your changes before using Stop garage.

No Python or Node.js installation is needed.
Keep the _internal folder beside S Garage.exe.

Installation guide: docs/INSTALLATION.md
Online help: https://github.com/Senior-S/S-Garage-Euro-Truck-Simulator-2
Discord: seniors

This is an early preview. Make a separate manual save for experimenting.
Automatic save backups are inside the selected save's garage-backups folder.
